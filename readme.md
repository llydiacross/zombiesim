# Z-Nation

Z-Nation is a third-person zombie-survival gamemode for Garry's Mod. Explore a
connected city, search for supplies, fight the infected, and build up your
survivor as you travel farther from safety.

## Getting started

1. Start a game with the Z-Nation gamemode.
2. At the launcher, choose a survivor or create one in an empty slot.
3. Deploy when you are ready to enter the world.

## In the city

- Explore districts connected by roads and travel gates.
- Search buildings, vehicles, and other places for useful items.
- Watch out for tougher enemies and better loot as you travel farther from a
  safe zone.
- Return to a den to use its services and prepare for another trip.

Z-Nation is in development, so maps and features may change between updates.
