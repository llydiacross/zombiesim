==================
ABOUT THIS FILE:
==================

A simple nighttime sky with crisp clouds and a bright moon.


==================
FOLDER CONTENTS:
==================

Maps - Contains a VMF map file with Light_Environment and Shadow values for the sky.
Materials - Contains materials in VMT and VTF form, ready to be used ingame.
MaterialSrc - Contains the source files for editing or compiling the materials as a VTF.
Raw - Contains raw output renders and source files.
TerragenSrc - Contains Terragen source files for the skybox.
